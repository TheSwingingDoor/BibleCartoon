# New Character Template

Copy this directory to `characters/<character-id>/` and create:

- `README.md`
- `character.json`
- `CANON.md`
- `VISUAL-SPEC.md`
- `EXPRESSIONS.md`
- `ANATOMY-AND-GESTURE.md`
- `WARDROBE.md`
- `VOICE-AND-BEHAVIOR.md`
- `SCENE-RULES.md`
- `PROMPT-PACK.md`
- `QUALITY-CONTROL.md`
- `CHANGE-CONTROL.md`
- `assets/reference/<id>-master-model-v1.png`
- `assets/asset-catalog.json`
- `assets/asset-manifest.json`

A character remains `draft` until its master reference, machine-readable record, prompt block, forbidden-drift list, and QA checklist agree.
