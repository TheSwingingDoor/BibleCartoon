# Abby visual references

## Primary identity reference

`reference/abby-master-model-v1.png` is the locked first reference for every Abby generation. It defines identity, proportions, eyes, fur, body, no-tail anatomy, default work outfit, pearl collar, centered oval gemstone, and line style.

## Secondary performance references

The six sheets under `generated/` are approved specialist references. Attach only the one that matches the shot:

- expression library;
- eyes and face construction;
- hands, gestures, and props;
- bartender actions;
- wardrobe details;
- Swinging Door bar blocking.

Generated images do not become canon merely by existing. Their status is recorded in `asset-catalog.json`; their dimensions and SHA-256 fingerprints are recorded in `asset-manifest.json`.
